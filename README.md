# YouTube Audio Downloader

A Python desktop application with a Tkinter GUI that downloads audio from YouTube videos using yt-dlp and converts it with ffmpeg.

## Features
- Paste a YouTube link and download the audio
- Simple graphical interface (Tkinter)
- Audio conversion handled by ffmpeg

## Requirements
- Python 3.10 or later
- [yt-dlp](https://github.com/yt-dlp/yt-dlp)
- [ffmpeg](https://ffmpeg.org/download.html), installed and added to your system PATH

## Installation
```bash
pip install yt-dlp
```
Then install ffmpeg from the link above and make sure `ffmpeg` runs from your terminal.

## Usage
```bash
python pythonpersonalproject.py
```
